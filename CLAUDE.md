# CLAUDE.md — Math Knowledge Graph

## Project overview

Permanent knowledge graph of mathematical concepts from Wikipedia. Graph data is pre-crawled once
via a Node.js script and stored as static JSON. A React + D3 app loads and visualizes it.

## Tech stack

- React 18, Vite 6
- D3.js 7 (force simulation, hybrid canvas/SVG, zoom)
- Anthropic SDK 0.35 (community labeling via `claude-sonnet-4-6`)
- Wikipedia API (`en.wikipedia.org/w/api.php`)

## Key files

| File | Purpose |
|------|---------|
| `scripts/crawl.js` | Full crawler: category-based harvest of 400+ math articles from Wikipedia |
| `scripts/quickstart.js` | Fast alternative: 63 curated articles, ~3 min runtime |
| `public/math_graph.json` | Pre-built graph data (generated by crawler, not committed) |
| `src/App.jsx` | Loads JSON, runs graph analysis, orchestrates filters and Claude call |
| `src/utils/graphAnalysis.js` | Brandes betweenness + label propagation (same as wiki-graph-explorer) |
| `src/utils/graphFilters.js` | Filter/search logic, radial initial positions, domain breakdown |
| `src/services/claudeService.js` | Claude prompt for math community labeling + structural gaps |
| `src/components/GraphCanvas.jsx` | Canvas edges + SVG nodes (hybrid for performance at 400+ nodes) |
| `src/components/InfoPanel.jsx` | Right sidebar: node details, community labels, domain breakdown, gaps |
| `src/components/ControlBar.jsx` | Search, community filter, centrality slider |

## Architecture

1. Crawler runs once offline → writes `public/math_graph.json`
2. App fetches JSON at startup, runs betweenness + community detection in-browser (~100-200ms)
3. Claude annotation is non-blocking — graph renders before labels arrive
4. Filters (search/community/centrality) use opacity dimming, not simulation restart
5. Canvas renders edges (fast for 2000+ edges), SVG renders nodes/labels (easier interaction)

## Getting started

```bash
npm install
cp .env.example .env   # add VITE_ANTHROPIC_API_KEY

# Generate graph data — pick one:
npm run quickstart     # 63 curated articles, ~3 min (good for testing)
npm run crawl          # 400+ articles, ~5 min (comprehensive, needs rate limit cooldown)

npm run dev
```

## Crawler rate limiting

Wikipedia's API allows ~200 requests/minute per IP for anonymous users. If you get repeated
429 errors, wait 30-60 minutes before re-running. The optimized crawlers make minimal requests:
- `quickstart.js`: ~10 API calls total (batched)
- `crawl.js`: ~62 API calls total (30 categories + 23 article batches + 9 outlink batches)

## Key differences from wiki-graph-explorer (parent project)

- **No seed input** — graph loads immediately from static JSON
- **Canvas + SVG hybrid** — canvas edges for performance, SVG nodes for interaction
- **Three-tier labels** — always/zoom-triggered/tooltip-only by centrality level
- **Structural gaps** instead of expansion suggestions (Claude output)
- **Domain breakdown** bar chart in InfoPanel (from `node.mathDomain` metadata)
- **ControlBar** — search, community filter (dropdown), centrality slider

## Conventions

- Dark theme: background `#0D0F14`, accent `#78B4D4` / `#6878A0`
- Inline React style objects (no CSS files)
- `node.mathDomain` = Wikipedia category that article was harvested from
- Node IDs use underscore-separated titles (same convention as wiki-graph-explorer)
